Privacy

CVX · last updated 18 August 2026

CVX is a command-line tool that renders CV PDFs on your own machine. It has no accounts, no telemetry, and makes no network calls. This page covers the one part of the project that is reachable over the internet: the two endpoints a ChatGPT Custom GPT calls to fetch CVX.

What the endpoints are

  • /gpt/bundle.json — returns the current CVX release as a file.
  • /gpt/version.json — returns the current version number and download links.

Both are static files served by GitHub Pages. They have fixed contents, accept no query parameters and no request body, and there is no application behind them. A request cannot send them anything.

What we collect

Nothing. We operate no server, no database, no logging and no analytics. There is no account to create and no cookie set by these endpoints.

Because the files are hosted on GitHub Pages, GitHub receives the requests and may record standard web-server information such as IP address and user agent under its own privacy statement. We do not have access to those records and do not process them.

Your CV never reaches us

This is the part worth being precise about. When you use a Custom GPT built on CVX:

  • The GPT calls the endpoints above to download the CVX program. That request contains no CV content — it carries no input at all.
  • Your CV is written and rendered inside ChatGPT's own sandbox, by the downloaded program. It is not transmitted to us at any point.
  • CVX itself makes zero network calls while it runs. Its schema, templates and fonts are embedded in the downloaded file.

Your conversation, your uploads and the files produced in that sandbox are handled by OpenAI under OpenAI's privacy policy and terms, not by this project. If you would rather nothing left your machine at all, run CVX locally instead — npx @hrtips/cvx — where no part of it touches the network.

Children

CVX is a developer tool for producing CVs and is not directed at children under 13.
